title: Applied Genomics
summary: Collaborative single-cell and transcriptomic analyses across tissues, species, and biological questions.
project_slug: applied-genomics
---

This project collects applied genomics work where large-scale transcriptomic data are used to resolve cell types, developmental states, aging features, tissue-specific RNA regulation, and evolutionary variation.

The common thread is using computational genomics to make complex biological systems more interpretable.
